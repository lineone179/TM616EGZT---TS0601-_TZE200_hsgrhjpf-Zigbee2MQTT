# TM616EGZT---TS0601-_TZE200_hsgrhjpf-Zigbee2MQTT
Custom Converter for Tuya TM616EGZT (Zigbee2MQTT) This external converter is designed for calibrating the limit positions (borders) of Tuya curtain motors that are recognized in Zigbee2MQTT as _TZE200_hsgrhjpf (e.g., model TM616EGZT with M515/M616 board).
